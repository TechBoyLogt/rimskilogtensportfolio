# Security Policy

This repository hosts a static personal portfolio site (HTML, CSS, and JavaScript) served via GitHub Pages. There is no backend, database, authentication, or user data collection, so the attack surface is minimal.

## Reporting a Vulnerability

If you find a security issue with this site (e.g. a vulnerable dependency, an XSS vector, or a misconfiguration), please report it privately by emailing **rimskilogtens@gmail.com** rather than opening a public issue. I'll acknowledge reports as soon as I can and fix confirmed issues promptly.
